DivOPD

A rollout-aware batch composer for on-policy distillation of multi-turn agents.

I built

The learner-side validate-cover-focus pipeline: reject turns with no valid teacher signal, sample trajectories before turns to preserve rollout coverage, cap per-rollout contribution, then prioritize turns with high sampled forward KL.

Hard part

A nominal 64-turn batch often represented only 4–8 effective rollouts. One rollout could contribute 24–40% of all tokens, while up to 27.8% of turns had no valid supervision. The loss looked correct, but the update unit was badly composed.

Result

Without changing the model, loss, optimizer, or rollout procedure, mean peak success increased from 77.4% to 83.7% across six 1.5B–7B settings and three environments. Average time-to-target improved by 1.78×.

Takeaway

For long-horizon agent training, batch composition is part of the learning algorithm. Which trajectories share an update can matter as much as the objective applied to them.

02 / 08 · 2026 · First author

BiPACE

A critic-free advantage estimator for long-horizon LLM agents.

I built

BiGPO groups behaviorally similar states using the actor's hidden-state geometry. PACE then estimates action-conditioned peer baselines inside each state group, producing local counterfactual credit without a learned critic or additional rollouts.

Hard part

Exact observation hashing created singleton groups with no learning signal, while a single group mean mixed state value with action quality. The estimator's comparison unit was wrong on both sides.

Result

On ALFWorld with Qwen2.5-7B, success increased from GiGPO's 90.8% to 97.1 ± 0.9%. At 1.5B scale, BiPACE reached 93.5 ± 1.2% versus 86.7%, and transferred to WebShop and TextCraft.

Takeaway

Useful credit comes from comparing actions taken in behaviorally equivalent states—not merely states with identical surface observations.

03 / 08 · 2026 · Builder

LongCat2.5 Agentic Data Engine

Executable SWE-SQL and OfficeQA-Pro training environments on Harbor.

I built

Task environments and an auditable pipeline covering multi-source document sampling, K3 question generation and solving, independent validation, programmatic answer recomputation, structured rubrics, and trajectory distillation.

Hard part

Generated office and SQL tasks can look plausible while containing ambiguous questions, unverifiable answers, or broken execution paths. Quality had to be established by independent solving and recomputation, not style alone.

Result

The pipeline produced 9,000 agentic tasks. Distilled K3 trajectories used to fine-tune Flash-26B-DSA improved OfficeQA-Pro Full from 46.6% to 60.2%, a gain of 13.5 percentage points.

Takeaway

For agent data, executability and auditability are product features. A smaller verifiable task set is more useful than a larger collection of plausible prompts.

04 / 08 · 2025 · First author

Text2Grad

Reinforcement learning from natural-language feedback.

I built

A semantic-alignment → reward-mapping → gradient-propagation loop that links phrases in a critique to the responsible token spans and converts that alignment into localized differentiable learning signals.

Hard part

Scalar rewards say whether an answer failed but not where or why. Free-form critiques contain that information, but they must be aligned to exact spans before they can update model parameters safely.

Result

Text2Grad outperformed PPO, DPO, and PRM-PPO across summarization, code generation, and open-domain QA: BLEU +25.3%, HumanEval+ +3.6, AlpacaEval +2.3, and 22% faster convergence.

Takeaway

Natural language can be more than an explanation layer. With explicit alignment, it becomes a precise optimization interface.

05 / 08 · 2025 · End-to-end owner

DRL-PUT

A production RL policy for personalized multi-objective ad ranking.

I built

The offline-training-to-online-serving stack: a personalized reward combining revenue and user value, a REINFORCE policy, continuous-action discretization, and grouped utility weights for real-time inference.

Hard part

The policy had to balance click, conversion, impression, and revenue objectives under sparse, high-variance rewards, user heterogeneity, seasonal drift, and production latency constraints at more than 100 million MAU.

Result

A 25% traffic A/B test at billion-impression scale delivered CTR +9.7%, CTR30 +7.7%, and CVR +1.26%, with no significant regression in core revenue metrics.

Takeaway

The best algorithm is the one that survives the reward distribution, action-space constraints, and serving path. Production design narrowed the research choice.

06 / 08 · 2024 · Lead

Code-IDE Evaluation & Data Engine

Automated evaluation and traceable preference data for coding assistants.

I built

A hybrid benchmark using chain-of-thought reasoning and self-reflection to score readability, style, and intent alignment, plus a reverse-distillation pipeline that mapped production failures to error types, repair paths, and training labels.

Hard part

Evaluation had to track human judgment while remaining fast enough to compare 8–10 candidate models. Training negatives also had to isolate a useful failure instead of bundling many unrelated errors.

Result

The evaluator reached 0.85+ Spearman correlation with human rankings and reduced turnaround from 2–3 days to hours. Step-level DPO and staged curriculum improved robustness on difficult boundary cases.

Takeaway

Evaluation and data design are one system: a useful evaluator should not only rank models, but also explain how failures become targeted training examples.

07 / 08 · 2026 · Equal contributor

SkillRL

A recursively evolving skill memory for LLM agents.

I co-built

A system that distills successful and failed trajectories into a hierarchical SkillBank, retrieves general and task-specific skills during interaction, and updates the bank when validation failures reveal missing knowledge.

Hard part

Raw trajectory memory is long, redundant, and noisy. The system had to compress experience into reusable procedural knowledge without losing the task-specific details needed for action.

Result

Across ALFWorld, WebShop, and search-augmented QA, SkillRL improved over strong baselines by roughly 15.3% overall. On ALFWorld, success increased from GRPO's 77.6% to 89.9%.

Takeaway

Agent memory becomes more useful when it stores abstractions that can change—not transcripts that only grow.

08 / 08 · 2026 · First author

Know2Say / BAEE

A black-box early-exit system for reasoning models.

I built

A behavioral probing framework that detects when an answer is already recoverable from partial reasoning, and Black-box Adaptive Early Exit, which uses free continuations for both detection and answer extraction.

Hard part

Forced extraction often failed even when free continuations already recovered the correct answer. The stopping method had to avoid changing the model's continuation distribution at exactly the moment it tried to save computation.

Result

Across five model configurations and three benchmarks, BAEE reduced serial generation by 70–78% while improving accuracy by 1–5 percentage points; thinking-mode models gained as much as 5.8 points.

Takeaway

A model can have a recoverable answer before it can obey a prompt to state that answer. Early-exit systems must account for the distribution shift they introduce.
